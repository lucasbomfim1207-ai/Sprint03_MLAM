##  Objetivo

A partir da base de dados **Global EV Charging Stations**, foram selecionadas variáveis numéricas para realizar:
- Análises de probabilidade assumindo Distribuição Normal;
- Modelagem preditiva com Regressão Linear.

Variável selecionada para os exercícios de probabilidade: **Charging Capacity (kW)** — assumida como seguindo uma Distribuição Normal, conforme orientação do desafio.

##  Como executar

1. Clone este repositório ou baixe o notebook.
2. Abra `notebook/Sprint03_MLAM.ipynb` no Google Colab ou Jupyter.
3. Certifique-se de que `data/ev_stations.csv` está no mesmo diretório referenciado no código.
4. Execute todas as células em ordem (Runtime > Executar tudo).
